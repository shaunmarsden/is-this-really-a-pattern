# Worked Example

A fictional team's retrospective feedback over four sprints. It tests both sides of the same trap: similar wording hiding different causes, and different wording hiding the same cause.

- [log.md](log.md): the feedback log as given
- [output.md](output.md): the pattern review [SKILL.md](../SKILL.md) produced
- [review.md](review.md): whether the output refused to merge entries on the shared word "communication", and whether it grouped the two differently worded blocked-review complaints as one real pattern
