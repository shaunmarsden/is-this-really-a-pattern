# Worked Example

A fictional team's retrospective feedback across four sprints, built to test both directions of the same trap: similar wording hiding different causes, and different wording hiding the same cause.

- [log.md](log.md): the feedback log as given
- [output.md](output.md): the pattern review [SKILL.md](../SKILL.md) produces
- [review.md](review.md): whether the shared word "communication" got correctly refused as a merge, and whether the two differently worded blocked-review complaints got correctly grouped as one real pattern
