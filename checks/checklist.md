# Human Review Checklist

Check these before you act on any finding.

- [ ] Repeated entries about the same instance count as one distinct instance, not several
- [ ] No cause was invented for an entry where the log records only the wording, not a diagnosed reason
- [ ] Similar wording with different causes wasn't merged into one pattern
- [ ] Different wording with the same cause wasn't split into separate, unrelated signals
- [ ] No percentage or rate came from a sample too small or mixed to support one
