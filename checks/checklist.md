# Human Review Checklist

Run through this before acting on any finding.

- [ ] Repeated entries from the same instance were counted as one distinct instance, not several
- [ ] No cause was invented for an entry where the log only records wording, not a diagnosed reason
- [ ] Similar wording with different causes was not merged into one pattern
- [ ] Different wording with the same cause was not split into separate, unrelated signals
- [ ] No percentage or rate was given from a sample too small or mixed to support one
