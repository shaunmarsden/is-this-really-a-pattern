# Worked Example Two: Repeat Complainers, Unknown Causes, and a Requested Percentage

The first [example](../example/) tests same-word-different-cause and different-words-same-cause. This one tests three different traps: one customer filing the same complaint several times looking like several instances, most of the log having no diagnosed cause at all, and a request to turn a small sample into a percentage.

- [log.md](log.md): a fictional month of support tickets for a small software product
- [output.md](output.md): the review, correctly counting one repeat complainer as one instance, refusing to invent causes for undiagnosed tickets, and declining to give a percentage
- [review.md](review.md): whether all three traps were actually caught
